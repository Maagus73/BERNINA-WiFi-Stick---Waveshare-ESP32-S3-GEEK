## English

This public export excludes the private PlatformIO/ESP-IDF/managed_components installation. Builds resolve dependencies from `platformio.ini`, `src/idf_component.yml` and `dependencies.lock`. Their own license files/notices remain applicable; the PolyForm Noncommercial project license does not replace them.

Key components include [ESP-IDF](https://github.com/espressif/esp-idf), [esp_tinyusb](https://components.espressif.com/components/espressif/esp_tinyusb), TinyUSB/FatFs/mbedTLS/cJSON libraries, Python and the Python container base image. Operators must validate image tags and platforms themselves.

`src/unicode_nfc_data.h` contains canonical Unicode tables generated by `tools/generate_unicode_nfc.py` (version 16.0.0). See [LICENSES/Unicode-3.0.txt](LICENSES/Unicode-3.0.txt), sourced from [Unicode License](https://www.unicode.org/license.txt). These tables contain no private NAS data.
